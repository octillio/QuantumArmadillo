# QuantumArmadillo
Quantum Armadillo for VLC

1. Make a folder for audio files.
2. Make as many subfolders of audio clips as you like (even millions if your memory allows)
3. Play folder on Shuffle / Repeat
4. Just think to communicate or write notes on paper.

Find soundpacks or soundboards anywhere online. Also you can acquire a voice recorder and record your own 1 to 10 second mp3s. I recommend the Olympus WS-822 because it also has a shuffle / repeat feature and supports up to 199 subfolders within the MUSIC folder and 200 mp3s per folder.
